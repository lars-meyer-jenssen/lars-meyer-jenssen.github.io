# Academic website – Lars Meyer-Jenßen

Static site for GitHub Pages (`lars-meyer-jenssen.github.io`). No JavaScript, build steps, plugins, external fonts or analytics are required.

## Local preview

Unzip the archive and double-click `index.html`. All internal navigation works offline. Internet access is needed only for outbound links.

## Legal / privacy note

`legal.html` now includes the university postal address approved by the site owner and a tailored German-language privacy notice for a static GitHub Pages site. The text is an informed template, not a substitute for individual legal advice. If you add analytics, forms, embeds or external fonts, review and update the notice. GitHub Pages websites are public once pushed to the publishing branch.

## Upload to GitHub (after final editorial check)

1. Open `https://github.com/lars-meyer-jenssen/lars-meyer-jenssen.github.io`.
2. Go to **Add file → Upload files**.
3. Upload the **contents** of this unzipped folder, not the ZIP itself. `index.html`, `style.css`, `research.html`, etc. must be in repository root, and the `assets` folder must remain intact.
4. Choose **Commit changes** to the `main` branch.
5. GitHub Pages was configured with `main` and `/(root)`; the website will update at `https://lars-meyer-jenssen.github.io`.

## Site structure

- `index.html`: Home
- `research.html`: research interests, projects, methods, VR-Lab and QuaMath
- `publications.html`: Open Science, selected publications, editorial work, invited talks
- `teaching.html`: teaching areas, philosophy, supervision
- `about.html`: academic background, clinical training, awards, service, outreach
- `contact.html`: contact information and academic profiles
- `legal.html`: Impressum and tailored privacy information
- `assets/`: user-provided portraits and favicon
